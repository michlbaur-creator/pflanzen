# Was wächst denn da?

**Eine naturkundliche Führung von Michael Baur — Frühblüher im Ebsdorfergrund**

Eine kleine Website mit 40 Frühblühern aus Wald und Wiese:
naturkundliche Tafeln, Fotos und Steckbriefe zu jeder Art.

👉 **Live-Seite:** https://michlbaur-creator.github.io/pflanzen/

## Aufbau

- `index.html` — Startseite mit Filter nach Farbe, Lebensraum, Blühmonat
- `arten/` — 40 Artseiten mit Tafel, Fotos, Steckbrief und Merksätzen
- `images/tafeln/` — naturkundliche Tafeln (Illustrationen)
- `images/fotos/` — Fotos aus der Region
- `assets/` — Stylesheet und Filter-Skript
